ATIF PORTFOLIO — VERCEL DEPLOYMENT

This archive is flattened: index.html is at the archive root.

1. Extract this ZIP.
2. In Vercel, create a NEW project or update the existing project using the extracted folder.
3. Set Framework Preset: Other.
4. Set Root Directory: leave as ./ (the folder containing index.html).
5. Leave Build Command empty.
6. Leave Output Directory empty / default.
7. Deploy.

Important:
- Do not set Root Directory to "site" for this package.
- Keep the assets/ folder alongside the HTML files.
- If replacing a Git-connected project, commit and push all extracted files.
